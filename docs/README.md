# Tài liệu

Đọc theo thứ tự này nếu mới vào:

1. [`VISION.md`](VISION.md) — xây cái gì, vì sao.
2. [`CONTEXT.md`](CONTEXT.md) — ngôn ngữ chung của domain (Space, Chương, Nguồn, Hoàn thành).
3. [`ARCHITECTURE_NOTES.md`](ARCHITECTURE_NOTES.md) — kiến trúc hiện tại và nợ kỹ thuật.
4. [`adr/`](adr/) — quyết định kiến trúc đã chốt.
5. [`DEVELOPMENT.md`](DEVELOPMENT.md) — chạy local, lệnh, quy ước.
6. [`ROADMAP.md`](ROADMAP.md) — việc đã làm / đang làm theo checkpoint.

Vận hành: [`DEPLOY.md`](DEPLOY.md), [`RUNBOOK.md`](RUNBOOK.md), [`LAUNCH_CHECKLIST.md`](LAUNCH_CHECKLIST.md), [`SURVIVAL.md`](SURVIVAL.md).
