## Question

`VISION.md` §3 names Notion, Class Central, and roadmap.sh as the real
competitive reference class (not Udemy). What do these and similar products
(NotebookLM-style tools, YouTube-playlist-organizer tools, "watch party for
learning" tools) show about real-world retention/community adoption for a
product whose only value is organizing free content the user already
chose? Are there known failure/success case studies specifically relevant
to "free curation layer over YouTube" as a category? Does this validate or
undercut the core bet in `VISION.md` §2?

## Resolution

Class Central and roadmap.sh are real, sustainable businesses (Class Central
~$5M revenue/13 staff, affiliate/report-driven; roadmap.sh ~700K MAU, acquired
by Insight Partners in 2022), but both grew via their own original curated
content plus SEO-driven discovery/community crowdsourcing — not by being a
neutral private wrapper around content a single user already chose, which is
exactly what this product's non-goals exclude at this stage. Direct
"YouTube-playlist-to-course" tools (YTCourse, SyncStudy, EverLearns,
track-my-course) exist and are alive but stay at hundreds-of-users scale, with
no found breakout success and now direct competition from YouTube's own
native "Courses" feature (2024). Behavioral research confirms the underlying
pain (YouTube's structural deficiency for self-learners) is real, but
anecdotal PKM/Notion-abandonment evidence suggests organizing tools without an
external reinforcement loop (community, deadlines, shared audience) are prone
to the same abandonment fate as the "Notion + willpower" status quo being
replaced. Verdict: the wrapper is necessary but likely not sufficient alone
for retention/community adoption — VISION.md's Phase 1 "small aligned group"
hedge and Phase 2 AI layer are probably doing real retention work, not
optional polish; see full findings in
`docs/wayfinder/checkpoint2-feasibility/research/comparable-products.md`.
